# AMF

A personal portfolio CV built with React, TypeScript, Tailwind CSS, and Vite.

Deployed on GitHub Pages: [flyingstarlai.github.io/amf](https://flyingstarlai.github.io/amf/)

## Tech Stack

- React + TypeScript
- Tailwind CSS (DaisyUI)
- Vite

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
